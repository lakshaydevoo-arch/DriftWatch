# Security policy

DriftWatch v0.x has **no authentication** and is meant for local or trusted
networks only (see [ARCHITECTURE.md](ARCHITECTURE.md#8-cross-cutting-concerns)).
Do not expose it to the internet.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[security advisories](https://github.com/lakshaydevoo-arch/DriftWatch/security/advisories/new)
rather than in a public issue. Include the affected component, steps to
reproduce and the impact. You can expect an acknowledgement within a week.
